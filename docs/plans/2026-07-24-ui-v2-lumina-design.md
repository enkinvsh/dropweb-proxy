# dropweb proxy — UI v2 «lumina» (дизайн)

Утверждено владельцем 2026-07-24. Чисто view/asset-слой: логика (controller, health, WebRTC, storage) не меняется.

## 1. Тулбар-иконка (вместо badge)

Badge («ON», «!») полностью убирается. Состояние несёт сам логотип через `action.setIcon`:

| Вариант | Состояния | Цвет марки |
|---|---|---|
| `off` (ч/б) | off, applying | `#FAFAFA` на тёмной подложке |
| `on` (цветной) | on (health ok, WebRTC ok) | неоновый брендовый (`icon.png`) |
| `problem` (оранжевый) | unreachable, conflict, error, WebRTC-конфликт/утечка | `#F59E0B` |

- Мастер-вектор: `dropweb-channel/assets/logo/dropweb-logo.svg` (fill-перекраска — геометрия трёх состояний идентична).
- Подложка: тёмная скруглённая плашка, радиус = 26/128 пропорционально размеру (16/32/48/128 px).
- «Оранжевый = всё проблемное»: любая проблема → открой попап/настройки.
- `applying` — ч/б (fail-closed: зелёный только при подтверждённом on).
- Title (tooltip) остаётся как сейчас, + новый ключ для WebRTC-утечки.

## 2. Попап

Маленький тёмный квадрат (~280px), фон `#030305`, «ничего лишнего»:

- **Один орб** — размытое радиальное свечение справа-сверху; цвет следует состоянию (зелёный / тусклый белый / оранжевый).
- **Круглая power-кнопка** ≈160px по мотивам `connect_circle.dart` (dropweb-app): линза `#15151D→#080810`, тонкое кольцо, halo-свечение, power-глиф. **Тап = toggle** (on→disable, иначе→enable). Состояние несёт сама кнопка: зелёная = вкл, тусклая ч/б = выкл, оранжевая = проблема.
- **Анимации** (из Flutter-спеки): включение bloom 420ms, выключение 360ms, applying — пульс 2600ms, нажатие scale 0.96/100ms. `prefers-reduced-motion` → без анимаций.
- Внизу капс-лейбл **SETTINGS / НАСТРОЙКИ** (i18n) → `openOptionsPage()`.
- Никакого видимого текста статуса. Для скринридеров — визуально скрытый `role="status"` (aria-live), при проблемах — существующие hint-строки.
- `host:port` из попапа убран — живёт в настройках.
- Скругление окна попапа контролирует браузер; радиус 26 живёт в иконке, шапке и карточке настроек.

## 3. Страница настроек (lumina, как в zenbot preview_dropweb.html)

- Body `#030305`; центрированная карточка ≤600px: фон `#0A1710`, бордер `1px #08431F`, радиус 26, overflow hidden.
- **Шапка**: полоса-кроп `header.png` высотой ~110px, `object-fit: cover`, WebP ~40KB в бандле, радиус 26 сверху (утверждён вариант «тонкая полоса-кроп»).
- **Статус-блок** (новое): текущее состояние + детали проблем (unreachable hint, причина конфликта, WebRTC-статус) — всё, что убрали из попапа.
- Форма type/host/port/bypass: тёмные инпуты-пилюли (радиус 26), Save — градиент `#006D5B→#009938`, бордер `#00A14C`; Cancel — прозрачная с бордером.
- Типографика: **Unbounded** (заголовки) + **Onest** (текст) — woff2-сабсеты latin+cyrillic в бандле. Outfit из письма кириллицы не имеет — сразу Onest (его же fallback).
